## 2. 기능별 동작

### F1. 오늘 화면과 하루 타임라인

- 무엇을 하는가: 앱 주소를 열면 오늘 화면이 바로 보인다. 하루를 0시부터 24시까지의 축으로 보여 주고 그 위에 점을 시각 순서대로 놓는다.
- 수용 기준
  - [ ] AC1. 앱 주소를 열면 첫 화면이 오늘 타임라인이다. 처음 열 때도 안내 화면이나 권한 요청 없이 오늘 타임라인이 보인다.
  - [ ] AC2. 08:12 시작 점, 12:10 기록, 19:40 기록이 있는 날을 열면 세 점이 시각 순서대로 놓이고, 사진과 글은 보이지 않는다. 날짜 옆에 하루 점이 하나 보인다.
  - [ ] AC3. 시작 점과 순간 기록이 없는 날을 열면 하루 점과 "조용한 하루"가 보인다. "기록 없음", "0개" 같은 문구는 보이지 않는다.
  - [ ] AC4. 타임라인 어디에도 기록 개수, 연속 기록 일수, 다른 날과의 비교가 보이지 않는다.
  - [ ] AC5. 기록을 추가하라는 문구, 배지, 알림이 없다.
  - [ ] AC6. 이전 날짜와 다음 날짜로 이동할 수 있다. 오늘보다 뒤 날짜와 처음 연 날보다 앞 날짜로는 가지 않는다.
- 확인 방법: AC1·AC2·AC3·AC6은 E2E 자동 테스트. AC4·AC5는 수동 확인으로 모든 화면을 훑는다.
- 예외: 같은 분에 기록이 둘 이상이면 점이 겹치지 않고 둘 다 누를 수 있다.

### F2. "오늘 시작" 점

- 무엇을 하는가: 사용자가 원하면 버튼을 눌러 오늘의 시작을 점으로 남긴다. 앱을 연 시각을 시작 시각으로 쓰지 않는다.
- 수용 기준
  - [ ] AC1. 오늘 화면에서 08:12에 "오늘 시작"을 누르면 오늘 타임라인 08:12 자리에 시작 점이 생긴다.
  - [ ] AC2. 오늘 시작 점이 이미 있으면 "오늘 시작" 버튼이 보이지 않는다.
  - [ ] AC3. 앱을 열기만 하고 버튼을 누르지 않으면 시작 점이 생기지 않는다.
  - [ ] AC4. 지난 날짜의 타임라인에는 "오늘 시작" 버튼이 없다.
  - [ ] AC5. 시작 점은 순간 기록 점, 하루 점과 모양이 다르다.
- 확인 방법: AC1~AC4는 E2E 자동 테스트. AC5는 수동 확인.
- 예외: 23:59에 누르면 그날 23:59에 남는다.

### F3. 하루 점

- 무엇을 하는가: 그 브라우저에서 앱을 처음 연 날부터 오늘까지 날짜마다 점 하나를 남긴다. 사용자가 아무것도 하지 않은 날에도 남는다.
- 수용 기준
  - [ ] AC1. 9월 3일에 처음 열고 9월 27일에 9월 아카이브를 열면, 3일부터 27일까지 모든 칸에 하루 점이 하나씩 있다. 앱을 한 번도 열지 않은 날도 같다.
  - [ ] AC2. 1일·2일 칸과 28일 이후 칸에는 하루 점이 없다.
  - [ ] AC3. 하루 점은 시각이 없어서 타임라인 축 위에 놓이지 않고, 시작 점·순간 기록 점과 모양이 다르다.
  - [ ] AC4. 하루 점은 지울 수 없다.
- 확인 방법: AC1·AC2는 단위 테스트(처음 연 날짜와 오늘 날짜를 바꿔 가며 계산). AC3·AC4는 수동 확인.
- 예외: 기기 날짜를 처음 연 날보다 앞으로 바꾸면 그 날짜에는 하루 점을 만들지 않는다.

### F4. 순간 기록 (사진 + 한 줄)

- 무엇을 하는가: 사진 한 장과 한 줄 글로 하루의 순간을 남긴다. 저장하면 타임라인에 점이 하나 생긴다.
- 수용 기준
  - [ ] AC1. 사진 한 장을 고르고 "점심 김치찌개"를 적어 저장하면 타임라인에 점이 하나 늘고, 그 점을 누르면 그 사진과 문구가 보인다.
  - [ ] AC2. 사진 버튼을 누르면 브라우저의 사진 선택 화면이 열리고, 사진 보관함 전체 접근을 묻는 창은 뜨지 않는다.
  - [ ] AC3. 사진만 있거나 한 줄만 있어도 저장된다. 둘 다 비어 있으면 저장 버튼이 눌리지 않는다.
  - [ ] AC4. 한 줄은 80자에서 더 입력되지 않는다.
  - [ ] AC5. 저장한 기록이 브라우저 탭을 닫고 Safari를 완전히 종료했다가 다시 열어도 남아 있다.
  - [ ] AC6. 기록을 저장할 때 사진과 한 줄이 서버로 전송되지 않는다.
- 확인 방법: AC3·AC4는 단위 테스트. AC6은 E2E 테스트에서 저장 중 나가는 네트워크 요청이 없는지 확인한다. AC1·AC2·AC5는 수동 확인.
- 예외: 사진 선택 화면에서 취소하면 기록 화면으로 돌아가고, 적어 둔 한 줄은 지워지지 않는다.

### F5. 기록 수정·삭제

- 무엇을 하는가: 이미 남긴 순간 기록의 사진, 한 줄, 카테고리를 바꾸거나 기록을 지운다.
- 수용 기준
  - [ ] AC1. 한 줄을 "점심 김치찌개"에서 "점심 된장찌개"로 고쳐 저장하면 점 상세에 바뀐 문구가 보인다.
  - [ ] AC2. 사진을 다른 사진으로 바꿔 저장하면 점 상세에 새 사진이 보인다.
  - [ ] AC3. 삭제를 누르면 확인 창이 한 번 뜬다. 확인하면 점이 타임라인에서 사라지고, 새로고침해도 없다.
  - [ ] AC4. 시작 점의 삭제·시각 수정은 PRD 미결 6이 정해지면 이 항목을 채운다.
- 확인 방법: AC1~AC3은 E2E 자동 테스트.
- 예외: 삭제 확인 창에서 취소하면 아무것도 바뀌지 않는다.

### F6. 촬영 시각으로 점 배치

- 무엇을 하는가: 사진에 들어 있는 촬영 시각(EXIF)을 읽어 타임라인의 실제 시각 자리에 점을 놓는다. 브라우저에서 촬영 시각을 받을 수 있는지는 PRD 미결 2에서 검증한다.
- 수용 기준
  - [ ] AC1. 오늘 14:32에 찍은 사진을 18:00에 골라 저장하면 점이 14:32 자리에 놓인다.
  - [ ] AC2. 촬영 시각이 없는 사진(예: 촬영 정보가 지워진 이미지)을 18:00에 저장하면 점이 18:00 자리에 놓인다.
  - [ ] AC3. 9월 25일에 찍은 사진을 9월 27일에 저장하면 점이 9월 25일 타임라인에 놓이고, 저장 뒤 9월 25일 타임라인이 열린다.
  - [ ] AC4. 사진 없이 한 줄만 저장하면 저장한 시각에 놓인다.
- 확인 방법: 단위 테스트. EXIF 촬영 시각이 있는 이미지, 없는 이미지, 다른 날짜 이미지를 테스트 자료로 준비한다. 추가로 iPhone Safari에서 실제 사진으로 AC1을 수동 확인한다.
- 예외: 촬영 시각이 미래이거나 처음 연 날보다 앞이면 저장한 시각에 놓는다.

### F7. 점 상세 펼치기

- 무엇을 하는가: 점을 누를 때만 그 점의 내용을 보여 준다.
- 수용 기준
  - [ ] AC1. 순간 기록 점을 누르면 사진, 한 줄, 시각이 펼쳐진다. 닫으면 다시 점만 보인다.
  - [ ] AC2. 시작 점을 누르면 시작 시각만 보인다.
  - [ ] AC3. 펼친 상태에서 수정(F5)으로 들어갈 수 있다.
- 확인 방법: E2E 자동 테스트.
- 예외: 사진을 읽지 못하면 사진 자리를 비우고 한 줄과 시각은 그대로 보여 준다.

### F8. 점 모양으로 카테고리 구분

- 무엇을 하는가: 기록할 때 카테고리를 고르면 점의 크기, 채움, 테두리가 바뀐다. 점의 색은 하나만 쓴다.
- 수용 기준
  - [ ] AC1. 서로 다른 카테고리로 저장한 두 기록은 타임라인에서 점 모양이 다르다. 두 점의 색은 같다.
  - [ ] AC2. 시작 점과 하루 점은 모든 카테고리의 순간 기록 점과 모양이 다르다.
  - [ ] AC3. 카테고리를 고르지 않고 저장하면 기본 모양으로 보인다.
- 확인 방법: 수동 확인. 카테고리마다 기록을 하나씩 만들고 타임라인과 월간 아카이브에서 모양을 비교한다.
- 예외: 카테고리 목록은 PRD 미결 5가 정해지면 채운다.

### F9. 월간 아카이브

- 무엇을 하는가: 한 달을 날짜별 칸으로 보여 주고, 각 칸에 하루 점과 그날의 점을 시각 위치대로 작게 그린다. 수치는 보여 주지 않는다.
- 수용 기준
  - [ ] AC1. 9월을 열면 1일부터 30일까지 칸이 보이고, 처음 연 날부터 오늘까지의 칸에는 하루 점과 그날의 점이 시각 순서대로 그려진다.
  - [ ] AC2. 개수, 합계, 연속 일수, 지난달과의 비교가 보이지 않는다.
  - [ ] AC3. 하루 점만 있는 날의 칸은 다른 날과 크기가 같고, 회색 처리·경고 표시 같은 다른 표시가 없다.
  - [ ] AC4. 날짜 칸을 누르면 그날의 하루 타임라인이 열린다.
  - [ ] AC5. 이전 달로 이동할 수 있다. 처음 연 날이 있는 달보다 앞으로는 가지 않는다.
- 확인 방법: AC1·AC4·AC5는 E2E 자동 테스트. AC2·AC3은 수동 확인. 점이 적은 달과 많은 달을 테스트 자료로 만들어 화면 시안 검증에 함께 쓴다.
- 예외: 처음 연 날보다 앞 날짜의 칸은 비워 둔다.

## 3. 데이터

모든 데이터는 그 기기의 브라우저 안에만 저장한다. 서버로 보내지 않는다.

| 항목 | 설명 | 필수 | 지우는가/남기는가 |
| --- | --- | --- | --- |
| 처음 연 날짜 | 하루 점을 만들기 시작하는 날짜 | 필수 | 브라우저 데이터를 지울 때까지 남긴다 |
| 기록 ID | 기록마다 하나 | 필수 | 기록과 함께 지운다 |
| 종류 | `시작` 또는 `순간` | 필수 | 기록과 함께 지운다 |
| 시각 | 점이 놓이는 날짜와 시각 | 필수 | 기록과 함께 지운다 |
| 시각 출처 | `시작 버튼`, `촬영`, `저장` 가운데 하나 | 필수 | 기록과 함께 지운다 |
| 사진 | 긴 변 2048px로 줄인 이미지 | 선택 | 기록과 함께 지운다 |
| 한 줄 | 최대 80자 | 선택 | 기록과 함께 지운다 |
| 카테고리 | 미결 5의 목록 가운데 하나 | 선택 | 기록과 함께 지운다 |
| 만든 시각·고친 시각 | 기록을 만들고 고친 시각 | 필수 | 기록과 함께 지운다 |

하루 점은 따로 저장하지 않고 처음 연 날짜와 오늘 날짜로 계산한다. 순간 기록에는 사진과 한 줄 가운데 하나가 반드시 있어야 한다.

## 4. 도메인 규칙

- 하루는 기기 시간 0시에 시작해 24시에 끝난다.
- 처음 연 날부터 오늘까지 날짜마다 하루 점이 하나 있다. 그래서 모든 하루에 점이 최소 하나 있다.
- 시작 점은 사용자가 "오늘 시작"을 누를 때만 생긴다. 앱을 연 시각을 시작 시각이나 기상 시각으로 기록하지 않는다.
- 시작 점은 하루에 최대 하나이고, 오늘에만 남길 수 있다.
- 순간 기록의 점 위치는 촬영 시각 → 저장 시각 순서로 정한다. 촬영 시각이 미래이거나 처음 연 날보다 앞이면 저장 시각을 쓴다.
- 어떤 화면에도 기록 개수, 연속 기록 일수, 다른 날·다른 달과의 비교를 보여 주지 않는다.
- 첫 버전은 알림을 보내지 않는다. 앱이 먼저 화면을 띄우지 않는다.
- 기록 내용(사진, 한 줄, 시각)을 서버로 보내지 않는다.
- 지운 기록은 되살릴 수 없다.

## 5. 기술 결정

| 결정 | 누가 정했나 | 이유 |
| --- | --- | --- |
| 첫 버전은 Next.js 웹 앱으로 만든다 | 사용자 | 익숙한 도구로 핵심 화면을 먼저 시험하고, 계속 쓰고 싶어 하는지 확인한 뒤 모바일 앱을 정한다 |
| 기록은 기기의 브라우저 안에만 저장하고 서버를 두지 않는다 | 사용자 | 계정 없는 익명 원칙, 첫 버전 범위 |
| 사진은 사용자가 고른 것만 받는다 | 사용자(원본 문서) | 개인정보 부담을 줄인다 |

배포할 곳은 PRD 미결 3, 모바일 앱 스택은 PRD 미결 7이다.

## 6. 비기능 요구

- 기록의 저장·조회·수정·삭제는 서버 요청 없이 브라우저 안에서 끝난다.
